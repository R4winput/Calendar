# 📅 Calendar

A simple desktop calendar application built with Python and Flet.

This project was one of my early experiments with graphical user interfaces, date handling and interactive applications in Python.

---

## ✨ Features

- 📅 Monthly calendar view
- 🖱️ Interactive date selection
- 🔄 Navigate between dates
- 🗓️ Date and calendar handling
- 🖥️ Graphical user interface
- 🎨 Custom UI elements

## 🚀 Getting Started

### Requirements

- Python 3.x
- Flet

### Installation

Clone the repository:

```bash
git clone https://github.com/R4winput/Calendar.git
cd Calendar
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python main.py
```
